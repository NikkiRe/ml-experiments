# Computer Vision: методы, результаты и запуск

Два учебных проекта по компьютерному зрению на **PyTorch**: сравнение стратегий transfer learning и обучение residual CNN с нуля. Репозиторий показывает подготовку данных, обучение, сравнение конфигураций, работу с отложенными выборками и разбор ограничений эксперимента.

**Авторы исходных работ: Кирилл Слепцов и Никита Евстигнеев.** Проекты выполнены совместно на основе учебных заданий и шаблонов. Это портфолио существующих экспериментов; новые запуски при подготовке репозитория не выполнялись.

## ResNet-50: перенос обучения

[Ноутбук с кодом, логами и результатами](../notebooks/resnet50_transfer_learning.ipynb) · [Одно разбиение, CSV](../results/resnet50_seed42.csv) · [Четыре разбиения, CSV](../results/resnet50_four_splits.csv)

**Задача.** Объединить девять классов ImageNet в три метакласса: фрукты, обувь и бытовая техника. Использовано 450 изображений из исходного `validation` ImageNet — по 50 на класс. Собственное стратифицированное разбиение по девяти исходным классам: 314 train, 68 validation, 68 test.

**Эксперименты.** Восемь конфигураций: замороженный backbone, обучение `layer4` и всей сети; линейная и MLP-головы; разные learning rate, dropout, weight decay и label smoothing. Для каждой конфигурации выполнено по четыре разбиения с seed `42, 1, 2, 3`: **32 обучения по 8 эпох**. Использованы предобученные веса torchvision `IMAGENET1K_V2`, AdamW, cosine scheduler и mixed precision на CUDA. Метрики — accuracy, macro-F1, cross-entropy; в ноутбуке сохранены classification reports и графики обучения. Код нового запуска также записывает confusion matrix и историю обучения в JSON.

**Результат.** На seed 42 конфигурация `G_frozen_lr1e-2`, выбранная по validation macro-F1 и затем validation loss, получила **accuracy 98,53% (67/68), macro-F1 0,9852** на test. Для этой конфигурации по четырём разбиениям: **accuracy 0,9890 ± 0,0074**, macro-F1 **0,9890 ± 0,0073** (mean ± sample std). В сводной таблице лучшие наблюдаемые test-метрики у других конфигураций не используются как критерий выбора модели.

![Сохранённые кривые обучения ResNet-50](../results/resnet50_training.png)

**Ограничения.** Это небольшая задача на три метакласса внутри домена предобучения. Одна ошибка на test меняет accuracy примерно на 1,47 п.п. Повторные разбиения пересекаются; среднее и стандартное отклонение не являются доверительным интервалом. Test-метрики всех конфигураций показаны в отчёте: дальнейший подбор по ним потребует нового отложенного набора. Сохранённые результаты не доказывают качество на полном ImageNet или новом домене.

## Спортивные фотографии: residual CNN с нуля

[Ноутбук с кодом, пояснениями и сохранённым результатом](../notebooks/sports_residual_cnn.ipynb)

**Задача.** Классификация изображений по 30 видам спорта: **4002 train и 150 отложенных изображений**, взятых из готового разбиения учебного архива.

**Реализация.** Собственные `Dataset` и residual-блоки, четыре стадии сети, BatchNorm, pooling, классификатор на 30 классов. Обучение с нуля: 30 эпох, batch size 64, CrossEntropyLoss, AdamW и CyclicLR. На train применяются горизонтальные и вертикальные отражения, elastic transform и перестановка цветовых каналов; на отложенной части случайных аугментаций нет. Реализованы сохранение и восстановление checkpoint, графики loss/accuracy.

**Результат.** Сохранённая строка последней, 30-й эпохи: **accuracy 0,820 (123/150)**. После восстановления лучшего checkpoint проходит проверка `accuracy > 0.8`; точное финальное значение этой ячейкой не напечатано, поэтому оно не заявляется.

![Сохранённые кривые обучения sports CNN](../results/sports_training.png)

**Ограничения.** Отложенная часть названа `test` в исходном коде и используется для выбора checkpoint. Она фактически выполняет роль validation; независимого финального test в этом эксперименте нет. Класс модели в исходнике называется `ResNet18`, но содержит по одному residual-блоку на стадию, а не стандартные два. Здесь он описан как **residual CNN из четырёх блоков**. Архитектура и процедура оценки при публикации не изменялись.

## Как запустить

Для чтения ноутбуков и сохранённых графиков обучение не требуется. Для нового запуска создайте окружение из корня репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter lab
```

Открывайте каждый ноутбук в новом Python kernel и выполняйте ячейки по порядку. `requirements.txt` перечисляет библиотеки, импортируемые в ноутбуках, и JupyterLab. Это не lock-файл исходной среды: точные версии всех библиотек исходного запуска не сохранены. В сохранённом выводе ResNet-50 указаны PyTorch `2.11.0+cu130` и Tesla T4. Для CUDA нужен подходящий NVIDIA driver и совместимая установка PyTorch/torchvision; sports-ноутбук явно использует `device='cuda'`.

### Данные для ResNet-50

Используется [ILSVRC/imagenet-1k на Hugging Face](https://huggingface.co/datasets/ILSVRC/imagenet-1k). Получите доступ к набору и примите его условия. Если каталог данных отсутствует, ячейка получения данных предложит авторизацию через `huggingface_hub.login()` и потоково сохранит выбранные девять классов. В исходном эксперименте выбран `SPLIT = "validation"`; смена на `train` означает другой эксперимент и существенно больший объём чтения данных.

Локальный путь по умолчанию — `data/imagenet9/`, внутри нужны девять папок с wnid, указанными в ноутбуке. Можно задать `IMAGENET9_DIR` до запуска Jupyter. Результаты нового обучения записываются в `runs/resnet50/`; путь меняется через `RESNET50_OUT_DIR`.

Ноутбук также определяет Colab/Kaggle. В Colab используются `/content/imagenet9` и `/content/resnet50-runs`; перед завершением сессии сохраните результаты отдельно. В Kaggle нужно подключить ImageNet с каталогами wnid; notebook ищет их в `/kaggle/input`.

`run_experiment` использует кеш JSON в каталоге результатов: при повторе с другими данными или настройками выбирайте новый пустой `RESNET50_OUT_DIR`. Для ячейки разбора ошибок нужны соответствующие `.pt`-веса; готовые веса в репозитории отсутствуют.

### Данные для sports CNN

Исходная работа получает `sports.zip` по [ссылке учебного задания](https://drive.google.com/uc?id=1biITy7cv0-lo-bwZrFkyDCGsEOWCBx5W). Распакуйте архив в `data/sports/` либо задайте `SPORTS_DATA_DIR`. Требуются `sports.csv` со столбцами `filepaths`, `labels`, `data set` и фотографии по относительным путям из CSV. Состав архива и его первоначальная лицензия отдельно не установлены; ссылка сохранена как происхождение фактически использованных данных.

Ячейка подготовки переходит в папку данных, после чего код работает с исходными относительными путями. Checkpoint `best.pth` создаётся в этой же папке.
