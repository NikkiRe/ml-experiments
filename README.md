Учебное ML-портфолио: **табличные данные, ансамбли, кластеризация и компьютерное зрение**. Пять ноутбуков с выполненным кодом, сохранёнными результатами и разбором ограничений.

## Classic ML

### Регрессия медицинских расходов: EDA, OLS и Lasso

[Ноутбук](notebooks/insurance_regression.ipynb) · [Сохранённые метрики CSV](results/insurance_regression_metrics.csv)

- 1338 строк, шесть признаков; pandas-агрегации и объединение таблиц, распределения и корреляции, визуализация категорий.
- `ColumnTransformer` + `StandardScaler` + `OneHotEncoder` внутри `Pipeline`; OLS и Lasso с `GridSearchCV`, пять folds, сравнение сценариев фильтрации выбросов.
- OLS на сохранённом test из **268 строк**: **R² 0,7836, RMSE 5796,28, MAE 4181,19**. Split 80/20, seed 42. Мягкая фильтрация с Lasso дала сопоставимый результат; агрессивная фильтрация по target ухудшила качество.

### Цены автомобилей: деревья и ансамбли

[Ноутбук](notebooks/used_cars_ensembles.ipynb) · [Сохранённые метрики CSV](results/used_cars_metrics.csv)

- Предобработка пропусков и редких категорий; сравнение linear regression, kNN, decision tree, bagging, blending и stacking.
- Подбор бэггинга: **360 конфигураций × 5 folds**. Отдельная base/meta-выборка для blending; OOF-предсказания в `StackingRegressor`.
- Базовый бэггинг на сохранённом test 20%, seed 42: **RMSE 1791,49, MAPE 23,35%**. Подбор бэггинга не улучшил test-результат. В отдельном блоке — собственный random forest на sklearn-деревьях для классификации региона insurance.

В исходном used-cars эксперименте заполнение пропусков и частоты категорий рассчитаны до split. Метрики сохранены как учебный результат; для строгого сравнения нужна повторная оценка с предобработкой внутри folds.

### Кластеризация: собственный k-means и библиотечные методы

[Ноутбук](notebooks/insurance_clustering.ipynb)

- Собственный k-means: назначение ближайшего центроида, пересчёт средних, остановка по сходимости.
- Сравнение с sklearn `KMeans`, `AgglomerativeClustering`, `DBSCAN`; `StandardScaler`, PCA до двух компонент и визуализация.
- ARI относительно регионов близок к нулю: собственный k-means **0,0019**, после scaling + PCA библиотечный k-means **0,0025**. Исследование структуры всего набора из 1338 строк, без train/test.

## Computer Vision

### ResNet-50: сравнение стратегий transfer learning

[Ноутбук](notebooks/resnet50_transfer_learning.ipynb) · [Четыре разбиения, CSV](results/resnet50_four_splits.csv)

450 изображений ImageNet, девять классов объединены в три метакласса. Сравнены замороженный backbone, частичный и полный fine-tuning, разные головы и регуляризация: **8 конфигураций × 4 разбиения = 32 обучения**. Конфигурация, выбранная по validation на seed 42: **67/68 верных ответов на test, accuracy 98,53%, macro-F1 0,9852**. Это небольшая подвыборка внутри домена предобучения.

### Спортивные фотографии: residual CNN с нуля

[Ноутбук](notebooks/sports_residual_cnn.ipynb)

30 видов спорта, 4002 train-изображения. Собственные Dataset и четыре residual-блока; аугментации, AdamW, CyclicLR, checkpoint и графики. Последняя эпоха: **accuracy 82% на 150 отложенных изображениях**. Эта часть используется для выбора checkpoint и выполняет роль validation; независимого финального test нет.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter lab
```

Каждый ноутбук открывайте в новом kernel и выполняйте сверху вниз. Зависимости перечислены без фиксации всей исходной среды; это не lock-файл. Для sports CNN нужен NVIDIA GPU с CUDA, для classic ML GPU не требуется. Полный grid search ансамблей может быть вычислительно затратным.

Данные и checkpoint не включены. Инструкции по получению файлов приведены в документации соответствующего направления. Для знакомства с работами достаточно прочитать сохранённые outputs — повторное обучение не требуется.
